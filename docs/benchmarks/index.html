FastPlay video player benchmarks

FastPlay is designed for fast local playback. This page tracks the metrics that matter for a fast Windows video player and will hold measured results as they are collected.

Download FastPlay for Windows View Source on GitHub

What we measure

These are the dimensions that determine whether a local video player feels fast in everyday use. FastPlay is built around the first few: open-to-first-frame latency and seek responsiveness.

Methodology (planned)

Measurements will use the in-app playback metrics FastPlay already records — open-to-frame latency, seek latency, and dropped frames — across a fixed corpus of local files, on documented hardware, with the same files compared against other players where relevant. The benchmark corpus and scripts live under bench/ in the repository.
