Fast Windows video player for local playback

FastPlay is a fast, lightweight native Windows video player built for local playback, smooth scrubbing, hardware-accelerated decode, and responsive controls.

A faster way to open and watch local files

Most of the time you open a video player, you are not managing a library or transcoding a stream. You are opening one local file and watching it. FastPlay is built around that single moment: how fast the file opens, how quickly the first frame appears, whether it resumes where you left off, and how cleanly it scrubs.

It is a fast Windows media player focused on local files, designed to open local videos quickly and seek responsively, with hardware-accelerated playback and a software fallback.

What makes it fast

  • Native Windows playback built in Rust
  • FFmpeg demux and decode for common local formats
  • D3D11 hardware decode with GPU-resident DXGI presentation
  • Responsive seeking with stale-work dropping during scrubs
  • WASAPI audio with an independent audio decode worker
  • Bounded queues and an explicit state machine, no plugin maze
FastPlay is designed for fast local playback. “Fastest video player” claims require measured comparisons — see the FastPlay benchmarks page.
