A lightweight video player for Windows

FastPlay is a lightweight native Windows video player for local files. It does less on purpose, so the path from double-click to watching stays short and the controls stay responsive.

Download FastPlay for Windows View Source on GitHub

Simple by design

FastPlay is a lightweight media player for local files. There is no media-library workflow, no plugin system, and no settings maze — just a fast native Windows window for the file in front of you.

What you get

  • A simple Windows media player focused on local playback
  • Fast startup and a low open-to-first-frame path
  • Smooth scrubbing and responsive seek behavior
  • Per-file resume without a persistent library
  • Hardware-accelerated playback with a software fallback
  • Keyboard-first controls with a hold-to-show overlay

What it intentionally leaves out

  • Media library, scraping, and collection management
  • Plugins and a web or browser UI
  • Network streaming and disc playback
  • Persistent playlists (the play queue is session-only)

If you need any of those, a full-featured player like VLC is the better fit. FastPlay is for users who mainly want a fast, lightweight Windows video player for local files. See how it compares as a VLC alternative for Windows.
